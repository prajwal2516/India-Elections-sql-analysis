# 🇮🇳 India General Elections 2024 - SQL Analysis

## 📌 Project Overview
This case study focuses on analyzing the results of the Indian General Elections 2024 using SQL. The objective is to extract meaningful insights related to seat distribution, party performance, alliances, and voting patterns.

---

## 📊 Dataset Description
The dataset consists of multiple CSV files:
- constituencywise_results.csv
- constituencywise_details.csv
- partywise_results.csv
- statewise_results.csv
- states.csv

These datasets include information about candidates, parties, votes, constituencies, and states.

---

## 🛠 Tools & Technologies Used
- SQL (MySQL / SQL Server)
- Excel (CSV datasets)
- GitHub for version control

---

## 🔍 Key Analysis Performed
- Total number of parliamentary seats
- State-wise seat distribution
- Seats won by NDA and I.N.D.I.A alliances
- Party-wise performance analysis
- Candidate-level vote analysis (EVM vs Postal)
- Winning and runner-up candidates
- State-level election insights

---

## 📈 Key Insights
- Identified total seats and distribution across states
- Analyzed alliance-wise dominance (NDA vs I.N.D.I.A vs Others)
- Evaluated party performance across different states
- Compared voting patterns using EVM and postal votes
- Extracted top-performing candidates based on votes
